  1. 빙하 타일 위에 숫자가 적힌 구슬이 나타납니다.
  2. 1번부터 순서대로 클릭하세요. 맞게 누르면 구슬이 사라집니다.
  3. 화면의 구슬을 다 누르면 다음 단계가 바로 나옵니다. 다 못 눌러도 2초가 지나면 구슬이 더 쌓입니다.
  4. 순서를 틀리거나 빈 타일을 누르면 그 자리에서 끝납니다.
  5. 22번까지 모두 누르면 클리어입니다.
